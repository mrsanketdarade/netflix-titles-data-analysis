Netflix Titles Data Analysis¶

Project Domain: Data Analytics | Exploratory Data Analysis | Data Visualization¶

Project Objective¶

  • Analyze Netflix movies and TV shows using the netflix_titles.csv dataset.
  • Clean missing values and standardize date and numeric columns.
  • Explore content types, release years, ratings, countries, genres, and movie durations.
  • Use visualizations to identify patterns in the Netflix content catalog.

Dataset Description¶

  • Dataset Name: netflix_titles.csv
  • Records: 8,807
  • Features: 12
  • Dataset type: Netflix movies and TV shows

Key Attributes¶

  • Content identifier: show_id
  • Content category: type
  • Title and description: title, description
  • People and origin: director, cast, country
  • Date and year: date_added, release_year
  • Classification: rating, listed_in
  • Runtime: duration

Analysis¶

  • More recent years may contain a larger share of the titles in this dataset.

Conclusion¶

  • Release-year distribution helps describe how recent the available Netflix catalog is.

Q3. How does movie duration vary by release year?¶

In [15]:
movies = df[df['type'] == 'Movie'].copy()
movies['duration_num'] = pd.to_numeric(movies['duration'].astype('string').str.extract(r'(\d+)')[0], errors='coerce')
sns.scatterplot(x='release_year', y='duration_num', data=movies)
plt.title("Movie Duration vs Release Year")
plt.xlabel("Release Year")
plt.ylabel("Duration (Minutes)")
plt.show()

Analysis¶

  • Each point represents a movie.
  • The plot compares movie release year with runtime in minutes.

Conclusion¶

  • The scatter plot helps inspect runtime patterns over time; it does not by itself establish causation.

Q6. What is the correlation between movie release year and duration?¶

In [18]:
movie_corr = movies[['release_year', 'duration_num']].corr()
sns.heatmap(movie_corr, annot=True, vmin=-1, vmax=1)
plt.title("Movie Release Year and Duration Correlation")
plt.show()

Analysis¶

  • The heatmap displays the Pearson correlation between release year and movie duration, using rows with valid numeric values.

Conclusion¶

  • Correlation describes the strength and direction of a linear relationship; it does not prove causation.

Step 4: Key Analytics Insights¶

  • The dataset contains both Movies and TV Shows.
  • Missing values occur in several descriptive columns and require appropriate handling.
  • Release-year and rating charts summarize the catalog's composition.
  • Movie-only duration analysis avoids mixing minutes with TV-show seasons.
  • Correlation analysis is limited to numeric fields and should be interpreted cautiously.

Final Conclusion¶

This project uses Pandas, Matplotlib, and Seaborn to clean and explore the Netflix titles dataset. It demonstrates missing-value treatment, date and numeric conversion, and visual analysis of release years, content types, movie runtimes, and ratings. The findings describe patterns in this dataset and should not be interpreted as causal claims or as a complete measure of Netflix's current catalog.
